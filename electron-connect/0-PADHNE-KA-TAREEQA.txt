# Poora agent set — ek hi build tag: wealth-recon-20261028a

Status page ne theek kaha tha: sirf main.js aur iris-row-filler.js naye thay,
baqi 13 modules purane tag (wealth-recon-20261027f) par thay. Ab ye folder
electron-connect ki poori copy hai, sab ek hi tag par.

Is folder mein: 30 files (saare .js, contracts .json, start-live.ps1,
renderer, preload, README). assets folder shamil nahi — aap ke paas pehle se
maujood hai, usay chhorna hai.

## Kya karna hai

1. Electron agent window band karein.
2. Neeche wale command se saari files copy karein (purani overwrite ho jayengi).
   assets folder ko haath na lagayein.

```powershell
cd C:\Users\User\Downloads\tr-pension-merge-branch-20261026

Expand-Archive -Path (Get-ChildItem -Filter "Agent-Full-20261028a*.zip" | Sort-Object LastWriteTime | Select-Object -Last 1).FullName -DestinationPath .\_agentfull -Force
Get-ChildItem .\_agentfull\agent-full-20261028a\* -File | Copy-Item -Destination .\electron-connect\ -Force

# tag check: sab ek hi hona chahiye
Select-String -Path .\electron-connect\iris-*.js,.\electron-connect\job-report.js,.\electron-connect\main.js,.\electron-connect\pension-guard.js -Pattern "BUILD_TAG = `"" | ForEach-Object { ($_.Line -split '"')[1] } | Sort-Object -Unique
```

Aakhri command ka output sirf ye hona chahiye:

```
wealth-recon-20261028a
```

3. Agent dobara start karein:

```powershell
.\electron-connect\start-live.ps1
```

(Security prompt aaye to R = Run once.)

4. TaxRocket ka status page refresh karein — ab "Desktop files are mixed
   versions" nahi aana chahiye.

5. Phir FBR connect -> Connect to FBR -> Start filing.
